# Narada Product Roadmap

## Phase 1 - Scriptural Q&A MVP

Goal:
Answer user questions using the Bhagavad Gita and one commentary.

Features:

* Verse database
* Semantic search
* Citations
* Natural language questions
* Source-grounded answers

Success Criteria:

* User can ask life questions
* System returns relevant verses
* Every answer includes references

---

## Phase 2 - Multi-Scholar Support

Goal:
Allow exploration of different traditions.

Features:

* Shankara commentary
* Ramanuja commentary
* Madhva commentary
* Scholar selection
* Compare interpretations

Success Criteria:

* Users can view multiple perspectives
* Differences are clearly explained

---

## Phase 3 - Concept Graph

Goal:
Reason through concepts rather than verses.

Features:

* Concept taxonomy
* Verse-to-concept mapping
* Concept browsing
* Concept-aware retrieval

Success Criteria:

* Better answers for indirect questions
* Improved retrieval quality

---

## Phase 4 - Wisdom Platform

Goal:
Expand beyond the Bhagavad Gita.

Features:

* Upanishads
* Yoga Sutras
* Additional texts
* Cross-text exploration

Success Criteria:

* Unified wisdom search across traditions
